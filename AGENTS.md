# Project journal

Read `JOURNAL.md` when starting work in this repository.

Update it after every meaningful step: investigation findings, decisions, changes, validation results, blockers, and handoffs. Keep entries short, conversational, casual, and in first person, using simple words.

Record a concise summary of what happened, the decision and its practical reason, relevant evidence or uncertainty, and the next step. Distinguish planned work from completed work and checks actually run from results reported in older documentation.

Append dated entries using Asia/Manila time. Preserve earlier entries; explain changed decisions in a new entry. Start the history from what is known and never invent earlier work or results.
