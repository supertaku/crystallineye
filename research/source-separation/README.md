# Source-separation decision gate

This experiment starts after the full-mix music/painting prototype passes its review. No source-separation model is part of the mobile core.

Use the same legally usable local tracks and compare Basic Pitch on the full mix against relevant stems from Demucs, BS-RoFormer and MelBand-RoFormer. Keep composer parameters and playback positions fixed. Record note precision/recall, continuity of the selected melody, harmonic stability, blind V2/V3 preference, processing time, working-set memory and model size.

Try vocals for the primary contour, accompaniment for harmony, drums for accents and bass for washes. Admit separation only if a visible full-mix failure improves consistently and the cost is acceptable. A higher transcription score alone does not establish a better painting.

No experiment has been run yet. All-In-One's upstream desktop pipeline uses Demucs for its own reference features; that dependency does not count as a controlled visual source-separation evaluation.
